#Требования
Windows, Visual Studio 2022 с компонентом разработки классических приложений .NET.

.NET Framework 4.7.2, Entity Framework 6.x.

SQL Server 2022 (или 2019) и SQL Server Management Studio.

Установленные Microsoft Word и Excel для экспорта отчётов (если реализовано).

#Возможности и роли
Роль	Возможности
Пользователь	Просмотр своих платежей, поиск, фильтры, сортировка, смена своего пароля
Администратор	Управление пользователями , управление категориями , управление платежами , просмотр диаграмм, экспорт отчётов
Авторизация выполняется по логину и паролю (с хэшированием SHA-1). После трёх неверных попыток входа появляется капча.

Особенности работы
Каскадное удаление: удаление пользователя или категории сопровождается удалением связанных платежей (настроено на уровне БД через ON DELETE CASCADE).

#Интерфейс
Главное окно содержит верхнюю панель навигации (кнопка «Назад», динамический заголовок страницы, кнопка смены темы) и нижнюю панель с текущей датой и временем.
Для выхода из приложения и удаления данных предусмотрены запросы на подтверждение.
